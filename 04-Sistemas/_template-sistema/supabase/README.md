# Supabase deste sistema

Este sistema é um módulo do ecossistema DCG. **O banco não é deste repositório**: é o projeto Supabase único da DCG, documentado no repositório central `DCG - Adapta Native/supabase/`.

Não crie migrations aqui. Mudança de banco é pedida por `DB_CHANGE_REQUEST_TEMPLATE.md` e nasce no repositório central.

## Ordem de leitura

1. `ECOSSISTEMA_DCG.md` — o ecossistema em uma página.
2. `AI_DB_CONTEXT.md` — tabelas, módulos e ações deste sistema.
3. Com o repositório central disponível: `supabase/docs/permissoes_e_login.md`, `supabase/docs/relationships.md`.
