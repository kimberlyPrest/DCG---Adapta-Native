# Contexto Operacional

Instruções que mantêm o repositório central e os repositórios dos sistemas alinhados.

- `FLUXO_DE_TRABALHO.md`: como implementar, testar, documentar e commitar.
- `COMO_CRIAR_SPEC.md`: SPEC antes de código ou banco.
- `SUBMODULES.md`: como registrar e atualizar os sistemas em `04-Sistemas/`.
- `BANCO_UNICO_SKIP.md`: as 4 bases Skip no mesmo Supabase — estado, regras e achados de segurança.

Inventário dos sistemas: `04-Sistemas/00 - Sumario Sistemas.md`.

Atualize esta pasta quando mudar o processo de trabalho, a lista de repositórios, a regra de SPEC ou o fluxo de commit.
